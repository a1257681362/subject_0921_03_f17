- `FlywayMigrationTest`（更新）：新库 V1→V5、旧库基线增量、V5 物理索引与双写台账，以及**种子 id=1 后 IDENTITY 序列拨到 2**（首次发布新版本不撞主键）的回归断言。

> 验证中发现并修复的真实缺陷：V5 最初用 MERGE 显式插入规则版本 id=1，H2 默认模式下不前进 IDENTITY 序列，导致首次发布新版本自增 id=1 撞主键。已在迁移脚本补 `ALTER TABLE … RESTART WITH 2`，并从备份恢复文件库重放验证、加回归测试。
